<h1 align="center">Basuruk Skills</h1>

<p align="center">Teach a man to skill, and he'll never go skill-less.</p>

A collection of [Claude Code skills](https://docs.claude.com/en/docs/claude-code/skills), installable in one command.

## Install

```bash
npx @basuruk/skills          # installs into ./.claude/skills
npx @basuruk/skills --global # installs into ~/.claude/skills
```

## Skills

- **notion-publish** — Publishes BMad-generated docs (briefs, PRDs, architecture, epics/stories) into Notion with proper formatting, without touching the source files.
